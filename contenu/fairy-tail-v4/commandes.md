La V4 garde les commandes de sa version Skript : une commande par pouvoir. Les objets de pouvoir s'utilisent d'un clic droit, et leur recharge s'affiche quand on les tient en main.

## Pour tout le monde

| Commande | Effet |
| --- | --- |
| `/ftckoimonrole` (alias `/monrole`) | Revoir son rôle |
| `/compo` (alias `/ftcompo`) | Composition de la partie (le host peut la cacher) |
| `/ftlist` | Les esprits de Lucy et de Yukino |

## Commandes des rôles

| Commande | Rôle | Effet |
| --- | --- | --- |
| `/ftesprit <esprit>` | Lucy, Yukino | Choisir son esprit, une fois |
| `/ftend accepter` ou `refuser` | Natsu | Accepter ou refuser le pacte du Livre d'E.N.D |
| `/ftaveugle <pseudo>` | Sting | Aveugler un joueur, une fois par épisode |
| `/amour <pseudo>` | Ichiya, Eve, Ren, Hibiki | Savoir si un joueur est de Blue Pegasus |
| `/ftchoisir <pseudo>` | Jellal | Choisir Erza ou Ultia |
| `/ftsauver <pseudo>` | Ultia | Ramener un joueur qui vient de mourir |
| `/ftliage <joueur1> <joueur2>` | Meldy | Lier deux âmes |
| `/fttartaros <pseudo>` | Keith | Ramener dans Tartaros un joueur tué par un démon |
| `/ftfind <pseudo>` | Ezer | Savoir si un joueur est de Tartaros |
| `/ftcopier <pseudo>` | Franmars | Copier un rôle |
| `/ftchat <message>` | Mald Gheel, Kyoka | Se parler en privé |
| `/ftreturn` | Mald Gheel | Ouvrir sa cage de ronces avant la fin |
| `/ftvoir <pseudo>` | Zeleph | Voir le rôle d'un joueur, une fois par épisode |
| `/guilds` | Zeleph, Acnologia, E.N.D | Coordonnées des bases de guilde |

Pour Ultia et Keith, cliquer sur le message de mort revient à taper la commande.

## Menu du host

Dans `/h`, puis Modes :

- **Composition** : une page par guilde, chaque rôle activable un par un.
- **Événements** : Rôle Troll et 4 Rois d'Ishgar (coupés par défaut).
- **Timers** : annonce des rôles à **20 min** par défaut.
- **Doc du mode** : envoie le lien de la doc dans le chat.
