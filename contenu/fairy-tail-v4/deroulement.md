## La carte

La partie se joue sur **FTUMAP**, une carte fournie avec le plugin (taille fixe). Chaque guilde a sa base :

| Guilde | Base |
| --- | --- |
| Fairy Tail | **-200 / -200** |
| Sabertooth | **200 / 200** |
| Blue Pegasus | **200 / -200** |
| Crime Sorcière | **-200 / 200** |
| Tartaros | **0 / 0** |

La barre d'action indique en permanence la direction et la distance de sa base. Zeleph et Acnologia, sans base, ont `/guilds` pour connaître celles des autres. Le host peut déplacer les bases dans la configuration.

## Calendrier

Un épisode dure **20 minutes**.

| Temps | Événement |
| --- | --- |
| 0:00 | Lancement sur FTUMAP |
| 19:20 | « Les rôles seront donnés dans **40** secondes » |
| 20:00 | Annonce des rôles (réglable dans les timers). Avec le Rôle Troll, tout le monde se croit Zeleph **1 min** d'abord |
| 30:00 | Quêtes tirées au hasard, une par joueur. Les 4 Rois d'Ishgar, si l'événement est actif |
| 1:10:00 | Fairy Heart : Mavis, si elle est en vie, prend sa puissance |
| Chaque épisode | Les parfumeurs de Blue Pegasus reçoivent leurs parfums |

Les quêtes et Fairy Heart se comptent depuis l'annonce des rôles : **10 min** et **50 min** après.

## Composition

Chaque rôle activé est donné à un joueur au plus. Les joueurs en trop deviennent des **Membres de guilde** sans pouvoir, répartis à tour de rôle entre les guildes activées (Tartaros compris). Le host active ou retire chaque rôle, guilde par guilde, dans le menu Composition.

## Morts

- Une mort est annoncée **5 s** après, avec le pseudo, le rôle et le camp du mort. Il laisse une pomme d'or.
- Si Ultia peut le ramener, elle a **10 s** ; si un membre de Tartaros l'a tué et que Keith peut le ramener, Keith a **5 s**. Le stuff attend leur décision.
- Mavis ne meurt pas tout de suite : son cristal apparaît (voir sa carte).
- Minerva tuée par Kyoka revient aussitôt dans Tartaros.
- Deux joueurs liés par Meldy meurent ensemble.

## Victoire

Un camp gagne quand il est le seul en vie. Les camps peuvent changer en cours de partie :

| Cas | Qui | Gagne avec |
| --- | --- | --- |
| Duo | Erza et Jellal, si Jellal la choisit | eux deux seulement |
| Fairy Destiny | Mavis | Zeleph |
| E.N.D | Natsu, s'il accepte le pacte | lui seul |
| Néo-Minerva, Retour de Keith | Minerva tuée par Kyoka, les morts ramenés par Keith | Tartaros |

Si Keith ramène E.N.D dans Tartaros et qu'un démon le tue ensuite, Tartaros gagne aussitôt.
