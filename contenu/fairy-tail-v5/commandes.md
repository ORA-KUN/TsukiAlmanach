Tout passe par `/ft` (alias `/fairytail`). Les pouvoirs à objet s'utilisent d'un clic droit ; les anciennes commandes de la V4 (`/ftesprit`, `/amour`, `/ftchat`…) marchent toujours.

## Pour tout le monde

| Commande | Effet |
| --- | --- |
| `/ft` | Aide, avec les commandes de ton rôle |
| `/ft role` | Ton rôle, ta guilde et tes pouvoirs |
| `/ft magie` | Ta réserve de magie |
| `/ft rang` | Ton rang de mage |
| `/ft quetes` | Tes quêtes (menu) ; `/ft quetes accepter <n°>` dans une guilde, `/ft quetes livrer` pour les livraisons |
| `/compo` | Composition de la partie |
| `/ft exposed <pseudo>` | Récompense de rang S : trois guildes, dont la sienne, annoncées dans le chat |

## Conseil des Maîtres

| Commande | Qui | Effet |
| --- | --- | --- |
| `/ft conseil <message>` | Maîtres | Parler au Conseil, sans pseudo |
| `/ft vote oui` ou `non` | Maîtres | Voter sur le sujet |
| `/ft quitter` | Maîtres | Quitter le Conseil |
| `/ft attaque` | Mald Gheel | Attaquer le Conseil, s'il y est invité |

## Menu du host

Dans `/h`, puis Modes :

- **Composition** : un onglet par guilde, chaque rôle activable un par un, ou toute une guilde d'un clic.
- **Événements** : quêtes, 4 Rois d'Ishgar, Conseil des Maîtres (actifs par défaut) et Rôle Troll (coupé par défaut).
- **Timers** : l'annonce des rôles se règle (**20 min** par défaut) ; les guildes sortent de terre et les quêtes ouvrent toujours à **20 min**.
