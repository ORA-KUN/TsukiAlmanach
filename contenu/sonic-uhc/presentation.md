**Sonic UHC** est un mode de jeu à rôles inspiré de la saga **Sonic the Hedgehog**, ère moderne (Colors, Unleashed, Frontiers, Forces, Sonic X Shadow Generations).

À **20 minutes**, chaque joueur reçoit un rôle parmi les **32** du mode. Il existe **4 camps** :

- les [Héros](./heros), qui gagnent avec les Héros ;
- l'[Empire Eggman](./empire), qui gagne avec l'Empire ;
- les [Ténèbres](./tenebres), qui gagnent avec les Ténèbres ;
- les [Solitaires](./solitaires), qui gagnent **seuls**.

Chaque rôle a **un seul pouvoir**. Le but : être le **dernier camp en vie**.

Pour y arriver, les joueurs comptent sur les [anneaux](./anneaux), les [Wisps](./wisps) et les sept [Émeraudes du Chaos](./emeraudes), mises en jeu par les [évents](./lieux) autour du **Temple de Gaïa**.

:::attention Avant de jouer
- Lis la page de ton camp dès l'annonce des rôles. `/sonic role` rappelle ton rôle à tout moment.
- Accepte le [pack de textures](./pack-de-textures) à la connexion : les objets du mode sont bien plus lisibles avec.
:::
